# Structure modulaire

Les pages spécialisées restent séparées du gros index :
- `journees.html` pour les journées
- `anglais.html` pour l'anglais de survie
- `valises.html` pour les valises
- `survivre-londres.html` pour les conseils pratiques
- `automne-londres-harry-potter.html` pour la surprise
- `menu.css` et `menu.js` pour le nouveau menu

Cette structure permet de modifier chaque partie indépendamment sans réécrire l'accueil.
